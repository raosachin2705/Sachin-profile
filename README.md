# Sachin Kumar — Personal Brand Website

A personal portfolio for Sachin Kumar, designed as a living personal-brand platform rather than a static CV.

## Stack
Next.js · TypeScript · Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content direction
The site currently covers About, Experience, Selected Work, Ideas and Contact. Case studies and writing can be expanded without changing the core design.
